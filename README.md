## How I write these up (~10 min per room)
Every writeup uses the same 4-point format:
1. **Objective** — what the lab set out to teach / the task to complete.
2. **Tools used** — tools, environment, or equipment used.
3. **Commands / steps taken** — the key steps, in order.
4. **Key takeaway** — the most important thing learned and how it transfers to real IT / security work.

Rules: finish the room first — only document rooms I have actually completed; concepts in my own words, no copied walkthrough answers; flip the Status in the file and in this index to Completed.

For any new room, copy `WRITEUP-TEMPLATE.md` into the right path folder.
